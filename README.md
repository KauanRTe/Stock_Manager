# 📦 Stock Manager

Bem-vindo ao **Stock Manager**! 🚀  
Este é um sistema de **gerenciamento de estoque** desenvolvido em Django.  

## 🔧 Tecnologias usadas:
- 🐍 **Python** + **Django** (Back-end)
- 📦 **SQLite** (Banco de dados)
- 🖥️ **HTML + CSS** (Front-end básico)
- 🛠 **Git/GitHub** (Controle de versão)

## 📌 Funcionalidades:
✔️ Cadastro de produtos  
✔️ Controle de entradas e saídas  
✔️ Relatórios de estoque  
✔️ Integração com Machine Learning
